## Changes and contracts

- Added `facetracking/Tracking/SessionState.swift`. `SessionState` owns authorization, route/scene eligibility, viewport and checked geometry revision, desired/active running state, camera status, checked session generation, alignment/following stage, raw face, accepted timestamp, positioning/future-lighting histories, watchdog baselines, interruption state, and typed failure.
- `SessionViewport` treats bounds differences below 0.5 point as noise relative to the last accepted viewport, so accumulated motion still becomes meaningful. A validity transition or any transform-revision change is always meaningful.
- Added `facetracking/Tracking/SessionTransition.swift`. `SessionTransition.reduce(state:event:configuration:)` is synchronous and pure; `SessionEvent` carries explicit monotonic milliseconds and owned values; ordered `SessionEffect` values request start/stop, watchdog/freshness scheduling or cancellation, and dismissal.
- Attempts invalidate `activeSessionID` before emitting teardown. Real geometry changes, retry, and explicit restart after following loss allocate a checked increasing ID and preserve stop-before-start effect order. Duplicate lifecycle/layout events emit nothing.
- Observations are rejected before mutation when the attempt is stopped, failed, wrong-generation, wrong-revision, or non-increasing. Current observations call the plan-01 positioning reducer; following loss remains `.following`. Lighting storage exists but stays `.unknown`/empty because classification belongs to plan 07.
- Freshness requires the expected accepted timestamp, retains the acquired stage, and expires only at age greater than 300 ms. Watchdog failure occurs only beyond 5,000 ms from attempt start or the last successful face/no-face analysis.
- Interruption is distinct from authorization and typed failure. Current failures survive late observations and require retry when recoverable. Session/revision overflow is explicit and non-retryable rather than wrapping.
- Added `facetrackingTests/SessionTransitionTests.swift` with nine deterministic tests covering S01–S06, race permutations, overflow, repeated lifecycle cycles, and effect ordering. Updated `facetracking/Tracking/AGENTS.md` and `facetrackingTests/AGENTS.md` with reducer ownership and fixture rules.
- No camera, Vision, asynchronous runner, clock, `Task`, framework buffer, or lighting classifier was added.
