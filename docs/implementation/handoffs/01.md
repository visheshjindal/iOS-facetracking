## Changes and contracts

- Added `facetracking/Tracking/TrackingModels.swift` with owned `Sendable`/`Equatable` value contracts: `FaceGeometry`, optional `FacePose`, `FaceSample`, `FaceLightingMetrics`, and `FrameObservation`. Session and geometry revisions are `UInt64`; observation time is monotonic `Int64` milliseconds; calculations are `Double`.
- `FaceGeometry.isUsableInViewport` requires finite center/dimensions, positive width/height, and intersection with the normalized viewport while preserving partially outside coordinates. `FaceSample.validated` validates geometry and pose independently; non-finite or missing pose becomes unknown rather than neutral.
- Added `PreviewGeometry.target(viewportWidthPoints:viewportHeightPoints:) -> FaceGeometry?`, implementing the single section-6 point-space oval formula and separate x/y normalization. Invalid viewport dimensions return `nil`.
- Added `facetracking/Tracking/PositioningRules.swift` with `TrackingStage`, `PositioningHint`, explicit `PositioningHistory`, `PositioningResult`, and the pure `PositioningRules.update(history:stage:target:face:timestampMS:configuration:)` transition.
- Positioning uses elapsed-time EMA, inclusive entry/exit pose hysteresis, the 300 ms continuity boundary and gap latch exception, exact hint priority, fixed-anchor drift, observation-driven 2,000 ms acquisition, following loss/recovery, raw-versus-filtered geometry separation, and positioning/pose-based lighting eligibility. It performs no clock reads and owns no display strings.
- Added named XCTest coverage P01–P09 in `facetrackingTests/PositioningRulesTests.swift`. No session reducer, camera, coordinate mapper, or lighting classifier from later plans was implemented.
- Added `facetracking/Tracking/AGENTS.md`, updated `facetrackingTests/AGENTS.md`, and added `Tracking/AGENTS.md` to the synchronized app-group membership exclusions. Xcode normalized the existing compact project-file serialization while saving that required exception; target names, settings, and dependencies remain unchanged.
