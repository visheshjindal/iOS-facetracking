## Changes and contracts

- Added `CaptureScreen`, `PositioningMask`, `FaceReturnGuide`, `TrackedFaceOverlay`, `LightingBadge`, and `GuidanceText`. They render immutable plan-07 projections and return native actions through injected closures; no view duplicates classification, filtering, acquisition, or lighting priority.
- Preview and overlays share one stable safe-area viewport. `PreviewView.bounds` is the sole live viewport-size authority passed to analysis; banner/badge/action layout never reports geometry. This fixes a physical report where the overlay’s sibling geometry could disagree with the actual preview and leave centering unsatisfiable. Initial and return guides use `SessionState.target`; following outline uses `guidance.trackedOval` raw geometry.
- The initial mask is an even-odd white surface with a transparent oval. Acquisition state changes immediately while mask opacity fades over 450 ms; Reduce Motion removes the presentation animation without changing reducer timing.
- Following retains the centered 3-point white return guide at 0.82 opacity, including during face loss, and draws a fresh raw-face ellipse with a 5-point `#00FF87` stroke. Decorative eyes use the specified target-relative centers/dimensions and do not rotate.
- Added typed localization/action/style mapping, exact section-9 English catalog values, manual catalog ownership for dynamically selected stable keys, badge colors/sizing, Dynamic Type styles, 44-point action targets, and basic decoration accessibility hiding/full compact badge labels.
- Wired Grant, Settings, Exit, Try again, and loss-only Restart to existing store/reducer actions. Ordinary face return remains following; Restart dispatches `restartAfterLoss` and begins fresh alignment.
- Added 22 deterministic `CaptureFixture` IDs and a DEBUG-only `-capture-fixture` launch harness. Fixture startup bypasses `CaptureDependencies.live()`, so UI tests/previews do not construct or request camera services; release builds contain no fixture selection path.
- Added `CapturePresentationTests` for U01–U04 and two camera-free XCUITests. Created `Resources/AGENTS.md`; updated CaptureUI, unit-test, UI-test guidance and project exclusions.
